## Reproduction (PowerShell, repository root)

Only run this when the donor Java source files are present. The recorded capture
used Java `26.0.2.1`. Build in an isolated temporary directory, capture to an
external candidate file first, and compare that output with the checked-in
vectors before considering any fixture update. Do **not** replace the vectors
as part of this Stage 01 closure task.

```powershell
$donorVectorBuild = Join-Path $env:TEMP ('haru-donor-rng-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $donorVectorBuild | Out-Null
try {
  javac -d $donorVectorBuild `
    data/reference-donor/internal/libs/lib/random/MersenneTwisterFast.java `
    data/reference-donor/internal/libs/lib/random/MTRandom.java `
    tests/core/lib/fixtures/stage01_random/DonorRandomVectors.java
  if ($LASTEXITCODE -ne 0) { throw 'Donor compilation failed' }
  $candidate = Join-Path $donorVectorBuild 'vectors.jsonl'
  java -cp $donorVectorBuild DonorRandomVectors | Set-Content -Encoding utf8 $candidate
  if ($LASTEXITCODE -ne 0) { throw 'Donor execution failed' }
  $committed = 'tests/core/lib/fixtures/stage01_random/vectors.jsonl'
  $expected = Get-Content -Raw -Encoding utf8 $committed
  $actual = Get-Content -Raw -Encoding utf8 $candidate
  if ($expected.TrimEnd() -cne $actual.TrimEnd()) {
    throw 'Donor output differs from committed vectors; investigate without overwriting'
  }
  uv run --no-sync pytest tests/core/lib/test_random.py tests/core/lib/test_random_generation.py --no-cov -q
}
finally {
  Remove-Item -LiteralPath $donorVectorBuild -Recurse -Force -ErrorAction SilentlyContinue
}
```

The Java compiler may emit an informational `strictfp` warning. The command
above is provided as reproducible evidence; **it was not executed during this
closure review**, because no HaruQuantAI checkout or donor Java sources were
mounted in the execution environment.
