Run all crosschecks independently from crosscheck filters failure
If turned off (default), when crosscheck filter on strategy fails no further crosschecks are evaluated.
If turned on, ALL crosschecks will be performed for strategy, even if some of cross checks don't pass the filtering.
Basic (fast)
Cross Check Settings
Filters
These cross checks require none or only one additional backtest, so they are fast.
Standard (slow)
Cross checks that require multiple additional backtests, thus multiplying the time of processing the whole strategy.
Extensive (slowest)
Walk-Forward process is very slow, it requires tens or even hundreds of repeated backtests of the strategy in different time ranges and settings.
