# Notes — settings tab
> A simple notepad for writing down notes about the configuration you are using.

**Field-level controls (for UI tests):** [fields/notes.md](fields/notes.md)

**Applies to:** Build, Optimize, Retest (shared).

## What it configures

Notes is a simple free-text notepad. It lets you write down remarks about the config you are using —
what you were testing, why certain options are set the way they are, or any reminder you want to keep
with the task.

## Main options

- **Notes text** — a single free-text field. Whatever you type is saved together with your project
  config, so it stays attached to the task.

## How it affects generation

None. Notes are purely informational and have no effect on how strategies are generated, optimized or
retested — they are stored alongside the project so the context travels with the configuration.
