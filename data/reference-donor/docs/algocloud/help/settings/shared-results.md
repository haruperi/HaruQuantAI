# Shared results

> Offline copy of the AlgoCloud help article (fetched 2026-08-07).

Here you can setup strategy backtest results for sharing.

In editor click on Share results:

[image]

You can either create insertable snippet (for external website) or simple link:

[image]

## Insertable snippet

Choose the name for shared strategy, skin (dark or light) and what snippet do you want to use.

You can also allow sharing strategy pseudo code and allow users to clone shared strategy (available only for AlgoCloud users).

[image]

Click on share to save the strategy to shared results.

## Simple link

Choose the name for shared strategy, turn sharing of pseudo code and allowing cloning on/off and click on Generate link:

[image]

Link will be displayed in window below:

[image]

Click on share to save the strategy to Shared results.

## List of shared strategy results:

Clicking on Actions allow you to see links for the strategy, possibility to clone it (if allowed) and option to remove sharing.

[image]

After opening the link of the shared strategy, if allowed, there are options to view source code and clone the strategy (only for AlgoCloud users).

[image]
