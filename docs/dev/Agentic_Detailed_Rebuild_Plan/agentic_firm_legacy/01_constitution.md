# Agentic Firm Constitution

> **Status:** Active supporting policy
>
> **Canonical requirements:** `app/agentic/README.md`

## Supreme law

Agents reason, research, challenge, explain, simulate, optimize, code, and propose.
Authenticated humans and deterministic domain services authorize and execute.

No title, prompt, model response, peer agreement, stored memory, or framework
feature changes that division of authority.

## Constitutional articles

1. **Human mandate.** The Owner defines objectives, environments, assets, budgets,
   approvals, and prohibited actions. Agents cannot amend the mandate.
2. **Deterministic authority.** Data, Strategy, Simulation, Optimization, Portfolio,
   Risk, Trading, Brokers, and UI/API retain their documented authority.
3. **Least privilege.** Every role and tool is denied unless explicitly registered,
   scoped, authenticated, budgeted, and valid for the current environment.
4. **Evidence before assertion.** Material claims identify point-in-time sources,
   hashes, availability, assumptions, uncertainty, and falsifiers.
5. **Dissent before consensus.** Independent briefs precede discussion; credible
   counterclaims and unresolved dissent survive synthesis.
6. **No invented reality.** Agents never invent data, performance, fills, approvals,
   source content, or deterministic results.
7. **No direct execution.** Agentic has no broker mutation tool, broker credential,
   mandate override, kill-switch clear, or direct execution route.
8. **Safe code.** Generated code is staged in isolation, fully attributable, and
   incapable of hot loading.
9. **Reproducibility.** Model, prompt, tool, policy, evidence, seed, cost, and
   configuration lineage accompany every governed result.
10. **Containment.** Injection, privilege, poisoning, drift, runaway work, or
    provider failure causes bounded deterministic containment.
11. **Economic honesty.** A complicated council must beat its simpler baseline
    after uncertainty, latency, and cost or be removed.
12. **Disable safely.** Removing Agentic cannot disable or weaken deterministic
    trading safety.

## Amendment rule

Changing an article requires an Owner-approved documentation plan that updates the
canonical Agentic README, affected owning-domain specifications, Project,
Architecture, acceptance evidence, and changelog before code changes.
