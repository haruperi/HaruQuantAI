- Donor informs; specification owns. Sole donor `SQX_145_REFERENCE_ROOT`; target `HARUQUANTAI_ROOT`. Never publish machine-specific paths.
- Current ledger/schema are `reimplementation.json` / `reimplementation.schema.json`, schema version 4. Read both in full before approved edits.
- One atomic independently testable claim per record. Allocate `SQX145-EV-NNNNNN` as highest allocated suffix + 1; current high-water mark 195; never reuse an ID.
- Observed = inspected support; inferred = bounded reasoning; normative = target decision; unverified = open hypothesis. Confidence: confirmed/high/medium/low/unverified; confidence never grants runtime authority.

- Record limitations, concrete validation procedure/expected observation, actual artifacts/time for passes, repository commit and review state. Static inspection is never donor execution.
- Preserve clean-room flags: proprietary/sensitive/personal payload false; paraphrased behavior only true.
- For future material finding corrections, add fresh records and reciprocal supersession/contradiction links; retain conflicting current findings until resolved.
- Validate JSON/schema, source IDs/locators, current record links, registry/proposal bindings, source hashes, member metadata and prescribed focused checks.
- Current inventory: [p00-inventory.json](p00-inventory.json), [ownership](p00-ownership.json), [complete metadata bindings](sqx145/metadata.json), [core gaps](p00-common-core.md), [release gates](p00-release-matrix.md).

- Documentation migration removes retired published donor records by explicit owner authority. No retired snapshot/root lookup remains in current tooling.
- Plan → owner approval → bounded edits → verification → walkthrough → separate owner commit gate; no donor/runtime/database operation is implied.
