## Method

The repository was scanned for class, type-alias and assignment definitions under `app/`
(excluding `__pycache__`, `node_modules`, `.next`, `dist`, `coverage`). Each required contract name was
matched exactly, then fuzzily by token-set overlap against every defined symbol. Exact matches are listed
with file and line. Near matches are recorded as `Current Candidate` only when the semantics were checked.

## Architectural collision affecting every contract

`AGENTS.md` section 1 establishes a **Function-Only Public API Surface** rule: the `__all__` of every
`app/services/[DOMAIN]/__init__.py` must consist exclusively of standalone functions, and classes must
remain internal. This was verified empirically across all fourteen domains:

a domain package root. This is a blocking owner decision recorded in `phase-0-findings-and-decisions.md`;
it is not resolved here.
