# UI language — is AlgoCloud available in my language?

> Offline copy of the AlgoCloud help article (fetched 2026-08-07).

# Currently available

AlgoCloud's UI is currently English only. There is no in-app language switcher yet.

🇪🇸 Spanish coming soon

A Spanish translation of the UI is in development and will be released in an upcoming update. Stay tuned.

Help Center articles are available in English at help.algocloud.com.

# Workarounds while you wait

-

Browser translation — Chrome, Edge and Safari can auto-translate the page. Right-click anywhere on the AlgoCloud app and choose Translate to [your language]. This is not perfect for technical terms (indicator names, order types) but covers menus and help text.

-

Multi-language support chat — you can contact support in any language. Our team reads Spanish, Czech, Slovak, German, Italian (and Fin AI can handle many others via automatic translation).

# Request another language

If you'd like AlgoCloud in a language other than English or Spanish, email [email protected] and tell us which one. Priority is driven by demand.

# ¿Cómo cambiar el idioma de AlgoCloud?

La interfaz de AlgoCloud está actualmente solo en inglés. Una versión en español está en desarrollo y se lanzará próximamente.

Mientras tanto, usa la traducción automática del navegador (Chrome, Edge, Safari: clic derecho → Traducir al español) para ver los menús en tu idioma.

Para soporte en español, escribe a [email protected] o usa el chat — nuestro equipo responde en español.

# Jak přepnout AlgoCloud do češtiny?

Rozhraní AlgoCloud je momentálně pouze v angličtině. Použij automatický překlad prohlížeče (Chrome, Edge, Safari: pravým tlačítkem → Přeložit do češtiny). Na podporu můžeš psát česky na [email protected].
