# StrategyQuant and AlgoCloud — are they bundled?

> Offline copy of the AlgoCloud help article (fetched 2026-08-07).

Short answer: No

StrategyQuant (SQ) and AlgoCloud are separate products. No StrategyQuant package includes free or discounted AlgoCloud access. If you want to use AlgoCloud, you need an AlgoCloud plan (Free, Basic or Pro) purchased directly at app.algocloud.com.

# Why users often ask about this

StrategyQuant and AlgoCloud share some DNA — AlgoCloud can import .sqx strategy files exported from StrategyQuant, and both products target algorithmic traders. It's a reasonable guess that buying one would unlock the other, but it doesn't. They are priced and sold independently.

# What SQ users do get on AlgoCloud

Even without a bundle, you can still use your SQ work on AlgoCloud:

-

Import .sqx strategies — export a strategy from StrategyQuant and import it into AlgoCloud (My strategies → Import). Run backtests and deploy it on a connected broker.

-

Free plan — AlgoCloud has a Free tier so you can try the platform without paying.

# "I bought SQ Premium / SQ Ultimate and expected free AlgoCloud Pro"

There has never been such a bundle. If a promotion, email or landing page suggested there was, please forward it to [email protected] — we want to make sure messaging everywhere is accurate.

If you'd like AlgoCloud Pro, see pricing at app.algocloud.com.

# Other questions

-

Do I need a StrategyQuant licence to use AlgoCloud? No. AlgoCloud is fully self-contained — you can build strategies from scratch in the Strategy Editor without SQ.

-

Can I export an AlgoCloud strategy to StrategyQuant? Only via the standard .sqx format where applicable.
