# ATM (Advanced Trade Management) — field reference (for UI tests)

> Exact controls, `ng-model` bindings and defaults for the ATM settings tab, extracted from the web plugin source.

Source: `internal/plugins/SettingsAdvancedTM/` (`advancedTM.html`, `addNewExitPopup.html`,
`AdvancedTMCtrl.js`, `AdvancedTMService.js`, `module.js`). Tab is registered as `SettingsTab` id `35`,
`dataItem: 'settings-advancedtm'`, `configElemName: 'ATMs'`, task:
`Build,Optimize,Retest,AutomaticRetest,NeuralNetworkTrainer`. No `testId` on the tab itself, but the panel
root carries `data-testid="settings-atm-panel"`. All controls live under `AdvancedTMService.config`
(`$scope.config` in `AdvancedTMCtrl`), persisted to the `ATMs` XML element.

## Enable / config source / size constraints

| Label | Config key (ng-model) | Type | Default | Options / notes |
|---|---|---|---|---|
| Enable ATM | `config.enableATM` | checkbox, `data-testid="settings-atm-enable"` | `false` | Master switch. Every other control on the tab is `ng-disabled` when this is off. Persisted as `ATMs[enable]`. |
| ATM config source — Use ATM defined below | `config.atmType` = `"FROM_CONFIG"`-equivalent (`atmTypes.fromConfig`, numeric `2`) | radio (`name="ATMTypeRadio"`) | — | "Use ATM defined below (overwrites ATM saved in strategy, if any)". |
| ATM config source — Use ATM from strategy | `config.atmType` = `atmTypes.fromStrategy` (numeric `1`) | radio (`name="ATMTypeRadio"`) | **default** (`config.atmType` initializes to this) | "Use ATM from strategy (if any)". |
| ATM config source — Generate ATM using config below | `config.atmType` = `atmTypes.generate` (numeric `3`) | radio, `data-testid="settings-atm-type-generate"` | — | Only shown when `isBuildTask`. Disabled unless `config.enableATM` **and** `$root.license.isUltimateVersion` (Ultimate-version-only feature). Has a "How it works" link (`onHowItWorks()`). |
| Size decimals | `config.sizeDecimals` | number spinner, `updateOn: 'blur'` | `1` | min 0, max 10, step 1. Persisted as `ATMs[sizeDecimals]`. |
| Minimum size | `config.minSize` | number spinner, `updateOn: 'blur'` | `0.1` | min 0.0000001, max 1000000, step 0.1. Persisted as `ATMs[minSize]`. |

### Define/Modify exit modal (`addNewExitPopup.html`)

Opened by "Add new exit" / clicking an exit row. Backed by `selectedExit` (a copy of the exit object being
added/edited), saved back into `config.exits` via the "Save" button (`onSaveExit()`).

**Size of position to close in this exit** (radio group `ATMPositionSizeRadio`, `ng-model="selectedExit.positionSizeType"`, default `"SizePercents"`):

| Label | Value | Extra field (ng-model) | Type | Default | Notes |
|---|---|---|---|---|---|
| Percent of position | `"SizePercents"` (`atmPositionSizes.percents`) | `selectedExit.positionPercents` | number spinner | `50` | min 0, max 100, step 1. |
| Fixed size | `"SizeFixedLots"` (`atmPositionSizes.fixedSize`) | `selectedExit.fixedLots` | number spinner | `0.01` | min 0.01, step 0.001. Unit "lot". |
| All remaining | `"SizeAllRemaining"` (`atmPositionSizes.allRemaining`) | — | — | — | No extra field; closes whatever is left of the position. |

**Exit level** (radio group `ATMExitLevelRadio`, `ng-model="selectedExit.exitLevel"`, default `"MultipleOfOriginalSL"`):

| Label | Value | Extra field(s) (ng-model) | Type | Default | Notes |
|---|---|---|---|---|---|
| Multiple of original order SL — Close at | `"MultipleOfOriginalSL"` (`atmExitLevels.slBased`) | `selectedExit.slMultiplicator` | number spinner | `1` | min 0.01, step 0.01. Unit "x Order Stop Loss". |
| Multiple of original order PT — Close at | `"MultipleOfOriginalPT"` (`atmExitLevels.ptBased`) | `selectedExit.ptMultiplicator` | number spinner | `1` | min 0.01, step 0.01. Unit "x Order Profit Target". |
| Fixed profit | `"FixedProfit"` (`atmExitLevels.fixedProfit`) | `selectedExit.fixedProfitType` (`<select>`) | select | `1` (Fixed value in pips) | Options: `1` = "Fixed value (in pips)", `2` = "ATR-Based". |
| ↳ if Fixed value (in pips) | — | `selectedExit.fixedProfitPips` | number spinner | `50` | min 0, step 1. Unit "pips". |
| ↳ if ATR-Based | — | `selectedExit.fixedProfitATRMultiplicator` / `selectedExit.fixedProfitATRPeriod` | number spinner / number spinner | `1.2` / `20` | Multiplier: min 0.01, step 0.01. Period: min 2, step 1. Rendered as "`multiplier` * ATR(`period`)". |
| Trailing stop | `"TrailingStop"` (`atmExitLevels.trailingStop`) | `selectedExit.trailingStopType` (`<select>`) | select | `1` (Fixed value in pips) | Same two options as Fixed profit's type select. |
| ↳ if Fixed value (in pips) | — | `selectedExit.trailingStopPips` | number spinner | `50` | min 0, step 1. Unit "pips". |
| ↳ if ATR-Based | — | `selectedExit.trailingStopATRMultiplicator` / `selectedExit.trailingStopATRPeriod` | number spinner / number spinner | `1.2` / `20` | Same shape as Fixed profit's ATR-based fields. |
| None — position will run until it is closed by exit rule | `"None"` (`atmExitLevels.none`) | `selectedExit.limitExitAfterBars` (checkbox, id `atm-limit-eab`) + `selectedExit.maximumBars` (spinner) | checkbox + number spinner | `false` / `50` | Checkbox label: "Define limit - Close after maximum `[spinner]` bars". Spinner: min 0, step 1. |

**Move SL 2 BE** — fieldset is present in the markup but **entirely hidden** (`ng-show="false"` unconditionally) and every input inside it carries `disabled`; the legend text itself says "NOT IMPLEMENTED YET". Not a reachable UI-test surface in the current build: `selectedExit.moveSL2BE`, `selectedExit.moveSL2BEAddPips`, `selectedExit.sl2beType`, `selectedExit.addPipsValue` exist in the data model (defaults `false`/`false`/`"Fixed Pips"`/`10`) and round-trip through XML, but cannot be set from the UI.

Modal footer: **Help** button (`onHelp()`), **Close** link, **Save** button (`onSaveExit()`).
