## Exclusion register

| Excluded behavior | Reason |
|---|---|
| MQ4 compilation or execution | Recognition is metadata-only; executing user source is outside the frontend mock and would misrepresent an absent engine. |
| Native SQX filesystem/database mutation | No backend exists. Browser-local files, downloads, and versioned persistence provide meaningful mock behavior. |
| Imported records inside `ExternalIndicators.json` | HaruQuantAI follows the donor's definition-only transfer boundary. |
| Strategy Builder use of external values | This task owns the Data Manager screen and dialogs; Builder integration requires its own audited workflow. |
| Legacy blank Recognize popup | The active controller opens a native file picker directly and never displays the bundled empty template. |
| QuantDataManager product variant | SQX intentionally hides External indicators there; HaruQuantAI presents the full research-platform profile. |
