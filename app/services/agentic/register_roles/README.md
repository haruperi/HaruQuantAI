# FEAT-AGT-REGISTER_ROLES

Provides `agentic.roles@1`. Role identity/version is immutable; prompts normalize to UTF-8/NFC with LF line endings and are sealed by prompt/manifest/composite SHA-256 digests. Floating model identities are rejected. Tool declarations do not grant tool authority, and role titles grant no authority. Resolution intersects current mandate scope, independent eligibility expiry/revocation/evaluation-only state, and explicit conflicts. Disposal is exact and source-generation bound.
