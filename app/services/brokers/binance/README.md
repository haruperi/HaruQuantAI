# FEAT-BRK-CONNECT_BINANCE — Binance Provider

Own one removable Binance profile. Spot connectivity and provider reads preserve the
proven donor behavior. USD-M and COIN-M profiles remain explicit but fail closed where
the donor has no implementation. The feature does not claim order transport merely
because the former global capability matrix named an operation.

Provides only `broker.provider.binance@1`. Provider selection, risk authorization,
instrument identity/mapping, and release governance are outside this feature.
